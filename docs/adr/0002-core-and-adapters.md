# 0002. A pure core and one adapter per platform

Status: accepted (2026-11-20)

## Context

Domain aliases were tied to Netlify: the sync script called the Netlify API and wrote `_redirects`, and the redirects page was generated by parsing that file. The path parameters in `from` (`/:url/:device`), the splat, and `200` as a rewrite were Netlify behavior, never defined here. The same aliases now also have to be served by a Docker image on CapRover, which proxies and redirects by itself.

## Decision

`domainAliases.json` stays the single source of truth and keeps its shape. A pure core (`Errors`, `Protocols`, `Utils`, `Schemas`, `Generators`) validates it and defines the matcher once: how a host and a path pattern match and how `:param` and `*` go into `to`. The mode comes from the `statusCode` as Netlify reads it (`200` proxies, a redirect code redirects). An optional `adapters` list restricts an alias to some platforms, and names the ones that take a host over (ADR 0007).

There are two adapters. `NetlifyAdapter` writes `_redirects` and the Netlify domain aliases, and Netlify's own engine redirects. `CapRoverAdapter` answers requests inside the Docker image with the core (`handle`) and registers the custom domains of the CapRover app (`sync`). Each declares its capabilities and `sync` and `check` fail naming the alias when one is missing.

Cloudflare Workers and a separate Docker adapter were considered and left out: the image already is the CapRover adapter's runtime, and there is no need for another platform today. A new adapter is one file plus one setup, and the core needs no change.

## Consequences

- The core imports no Node built-in (lint and a test), so every test of it needs no network.
- Netlify keeps its own matching, so its behavior is checked by tests of the generated file; the matcher defines the same semantics for CapRover (a host with no path matches only `/`; the query string is kept on the target).
- The image has no install step: the server imports only Node built-ins.
- A semantic difference between platforms is a declared capability, not a production surprise.
